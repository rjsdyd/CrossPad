# Login

## 사용자 로그인 페이지

- **인증 폼**: 이메일과 비밀번호를 입력받아 로그인을 수행합니다. 화면 중앙에 정렬되어 있습니다.
- **API 연동**: `axios.post`를 사용하여 백엔드(`localhost:8080/api/members/login`)와 통신합니다.
- **로그인 성공 처리**: 로그인이 성공하면 백엔드에서 반환된 사용자 정보(닉네임 등)를 `onLoginSuccess` 핸들러를 통해 최상위 `App.jsx`의 `user` 상태에 업데이트하고 마이페이지로 이동합니다.
- **회원가입 이동**: 계정이 없는 사용자를 위해 회원가입 탭(`SIGNUP`)으로 전환하는 버튼을 제공합니다.
