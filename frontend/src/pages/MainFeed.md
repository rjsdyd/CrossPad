# MainFeed
## 플랫폼별 게임 리스트를 보여주는 메인 화면

### 주요 기능
- **플랫폼 필터링**: `activeTab`에 따라 백엔드 API(`GET /api/games`)에서 목록을 불러와 렌더링
- **상세 페이지 전환**: 개별 게임 카드를 클릭하면 `selectedGameId` 상태를 변경하여 `GameDetail` 컴포넌트로 화면 전환 (조건부 렌더링 적용)
- **상태 초기화**: 다른 플랫폼 탭을 누르면 선택된 게임 ID를 초기화하여 다시 리스트 화면으로 자동 복귀
