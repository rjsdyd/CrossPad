# SearchPage
## 게임 검색 및 명작 추천 페이지

### 주요 기능
- **게임 검색**: 검색어 입력 후 백엔드 API를 통해 매칭되는 게임 목록을 가져와 렌더링
- **명작 추천 태그**: 닌텐도 및 플레이스테이션 대표작들을 빠르게 검색할 수 있는 추천 버튼 제공
- **최근 검색어**: 검색했던 기록을 저장하고 개별 삭제할 수 있는 칩(Chip) UI 제공

### 업데이트 내역
#### 2026-05-21
- **UI/UX 개선**: 로딩 중 덜컹거림(Layout Shift) 방지를 위한 최소 높이(`minHeight`) 및 반투명(opacity) 전환 효과 적용
- **디자인 고도화**: 투박한 이모지 대신 `lucide-react` 아이콘 적용, 추천 태그에 플랫폼별 브랜드 컬러(닌텐도 레드, 플레이스테이션 블루) 그라데이션 적용
- **검색 결과 최적화**: 화질이 낮은 썸네일 대신 고화질 포스터(`t_cover_big`)로 교체 및 검색 결과 클릭 시 상세 페이지(`GameDetail`)로 부드럽게 이동하도록 연결
- **스타일 충돌 해결**: `MainFeed`와의 CSS 클래스명 충돌 방지를 위해 `search-result-*` 접두사로 클래스명을 분리하여 독립적인 스타일링 보장
