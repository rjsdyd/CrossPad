# GameDetail
## 게임 클릭 시 진입하는 상세 전시실 (트레일러, 찜)

### 주요 기능 (최근 업데이트)
- **고화질 이미지**: IGDB API 썸네일(`t_thumb`) 대신 고해상도(`t_1080p`) 포스터 및 스크린샷 적용
- **레이아웃 분리**: 상단에는 게임 핵심 정보, 하단에는 미디어(트레일러/스크린샷) 영역으로 분리하여 가독성 향상
- **라이트박스 갤러리**: 스크린샷 클릭 시 화면에 꽉 차는 모달(확대 창) 제공
- **갤러리 네비게이션**: 모달 내에서 이전/다음 화살표(`ChevronLeft`, `ChevronRight`) 및 닫기(`X`) 버튼 기능 구현 (이벤트 버블링 방지 적용)
