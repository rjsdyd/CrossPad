# ReportModal
## 플랫폼 내 악성 리뷰를 신고하기 위한 오버레이 팝업 모달

### 주요 기능
- **신고 사유 선택**: 욕설, 스팸, 음란성 내용, 스포일러, 허위정보, 기타 등 라디오 버튼(Radio)을 통한 사유 선택 제공
- **상세 내용 작성**: '기타' 사유 선택 시 최대 200자까지 작성할 수 있는 텍스트 에어리어(Textarea) 동적 렌더링
- **API 연동**: 선택한 사유와 내용을 취합하여 백엔드(`POST /api/reports`)로 신고 접수
