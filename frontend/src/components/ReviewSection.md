# ReviewSection

## 개별 게임 상세 페이지 내 리뷰(한줄평) 관리 컴포넌트

- **리뷰 작성/수정/삭제**: 1계정 1리뷰 원칙 가드 적용 및 별점(0~5점) 기능
- **평균 평점 제공**: 해당 게임에 작성된 모든 리뷰의 평점 평균을 계산하여 노출
- **리뷰 열람**: 다른 유저들이 작성한 리뷰를 페이지네이션 형태로 제공

### 업데이트 내역
