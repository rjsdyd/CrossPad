# ReportListPage
## 플랫폼 내 신고 접수 목록을 확인하고 처리하는 관리자용 대시보드 페이지

### 주요 기능
- **신고 내역 조회**: 백엔드 API에서 접수된 신고 목록을 불러와 2열 그리드(Grid) 카드 형태로 렌더링
- **신고 정보 표시**: 신고 사유, 신고일자, 신고자/신고당한 유저 닉네임, 게임 제목 및 상세 내용 제공
- **신고 처리(이동하기)**: 처리 완료 및 상세 검토를 위해 버튼 클릭 시 해당 신고 카드를 화면에서 즉시 제거(백엔드 DELETE API 호출)하며, 새 창(`_blank`)으로 연결된 게임 상세 페이지를 띄움
