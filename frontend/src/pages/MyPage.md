# MyPage

## 유저 마이페이지 컴포넌트

- **유저 정보 확인**: 로그인한 유저의 닉네임, 이메일, 권한 등급(관리자/일반) 확인 기능
- **페이지 이동 연결**: 권한에 따라 '관리자 대시보드' 또는 '내 찜 목록 보러가기' 버튼 렌더링
- **로그아웃**: 전역 로그아웃 핸들러 트리거
