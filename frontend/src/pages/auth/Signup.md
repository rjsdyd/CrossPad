# Signup

## 신규 사용자 회원가입 페이지

- **실시간 유효성 검사**: 사용자가 입력하는 비밀번호의 길이를 실시간으로 체크(8자 이상)하여 조건 충족 시에만 가입 버튼을 활성화합니다. 파생 상태(Derived State) 변수를 사용하여 불필요한 `useEffect` 사용을 방지했습니다.
- **API 연동**: `axios.post`를 통해 백엔드(`localhost:8080/api/members/signup`)로 이메일, 비밀번호, 닉네임 정보를 전송해 계정을 생성합니다.
- **가입 완료 처리**: 회원가입이 성공하면 알림(alert)을 띄운 후 곧바로 로그인 화면(`LOGIN`)으로 상태를 전환하여 사용자 경험(UX)을 높였습니다.
