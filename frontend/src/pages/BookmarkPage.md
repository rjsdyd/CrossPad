# BookmarkPage
## 사용자가 찜한(북마크한) 게임 목록을 모아서 보여주는 전용 페이지

### 주요 기능
- **찜 목록 조회**: 현재 로그인한 유저의 고유 ID를 기반으로 백엔드에서 찜한 게임 목록을 불러와 렌더링
- **찜 취소 로직**: 개별 게임 카드의 하트 버튼을 클릭하여 즉시 북마크를 해제하고, 프론트엔드 상태 갱신을 통해 화면에서 게임 카드를 제거
