# SkeletonCard
## 로딩 중 화면의 덜컹거림(Layout Shift)을 방지하기 위한 뼈대 UI 컴포넌트

### 주요 기능
- **시각적 안정성 제공**: 백엔드에서 검색 결과 등 데이터를 불러오는 동안, 게임 카드의 레이아웃(커버 이미지, 제목, 평점, 요약 텍스트)을 미리 보여주어 사용자 경험(UX) 개선
- **CLS(Cumulative Layout Shift) 방지**: 실제 데이터가 렌더링될 때의 `search-result-card`와 동일한 크기와 구조를 가져, 뼈대에서 실제 카드로 전환될 때 화면이 출렁이는 현상 차단
- **상호작용 제어**: 아직 데이터가 없는 로딩 중에는 사용자가 카드를 클릭할 수 없도록 커서 스타일(`cursor: default`) 변경 및 클릭 이벤트 비활성화(`pointer-events: none`) 적용
