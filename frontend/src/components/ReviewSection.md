# ReviewSection
## 특정 게임에 대한 유저들의 평가(리뷰)를 조회하고 작성/수정/삭제/신고하는 메인 컴포넌트

### 주요 기능
- **리뷰 CRUD**: 리뷰 작성, 목록 조회, 내가 작성한 리뷰에 한하여 수정 및 삭제 기능 제공
- **평점 계산**: 전체 리뷰의 평균 별점을 계산하여 섹션 헤더에 표시
- **페이지네이션**: 무한 스크롤 대신 리뷰 목록을 3개씩 끊어서 보여주는 클라이언트 사이드 페이징 적용
- **신고 기능**: 일반 유저가 타인의 악의적인 리뷰를 신고할 수 있는 기능 제공
