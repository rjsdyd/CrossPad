# AdminDashboard
## 플랫폼 전체 회원 권한 조정 및 탈퇴 관리 대시보드

### 업데이트 내역
#### 2026-05-21
- **권한 강등 기능 추가**: 타 관리자의 권한을 '일반 유저'로 롤백시킬 수 있는 `권한 강등` 기능 및 안전장치(본인 계정 강등 불가) 구현
- **에러 핸들링 보강**: 승급/강등/탈퇴 처리 시 서버 에러 메시지가 없을 경우(`undefined`)를 대비한 대체 알림 메시지 적용
- **UI/UX 개선**: 대시보드 타이틀 중앙 정렬 및 이모지 대신 세련된 `lucide-react`의 `Shield` 아이콘 적용

#### 2026-05-22
- **모바일 반응형 최적화**: 모바일 등 좁은 화면에서 테이블이 찌그러지지 않도록 가로 스크롤(Swipe) 기능 전면 적용
- **UI/UX 개선**: 승급, 강등, 탈퇴 액션 버튼의 가로 너비(105px)를 통일하고, 텍스트가 두 줄로 꺾이지 않도록(`white-space: nowrap`) 강제하여 표 내부의 시각적 정렬(칼각) 완벽 구현
