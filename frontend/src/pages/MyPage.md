# MyPage
## 사용자 프로필 및 계정 관리 페이지

### 주요 기능
- **내 정보 조회**: 로그인한 유저의 이메일, 닉네임, 회원 등급 표시
- **관리자 분기**: 현재 로그인한 유저의 등급이 `ROLE_ADMIN`일 경우에만 관리자 대시보드로 진입할 수 있는 특수 버튼 노출

### 업데이트 내역
#### 2026-05-21
- **텍스트 다듬기**: "최고 관리자" → "관리자", "일반 회원" → "일반 유저"로 직관적인 한글 명칭 적용
- **디자인 개선**: 관리자 대시보드 진입 버튼의 이모지를 `lucide-react`의 `Shield` 아이콘으로 변경하고 레이아웃 정렬 최적화

#### 2026-05-22
- **모바일 내비게이션 바 연동 최적화**: 스마트폰 뷰 하단 탭(BottomNav) 버튼이 확장됨에 따라, 좁은 화면에서도 로그인 및 마이페이지 전환 상태가 매끄럽게 동기화되도록 접근성 강화
- **전역 스타일 정비**: 로그인/회원가입 에러 메시지 UI 고도화(흔들림 애니메이션) 및 전역 다크 테마 폰트 컬러 일관성 확립

#### 2026-05-27
- **찜 목록 진입 기능 추가**: 일반 유저(`ROLE_USER`) 계정일 경우, 마이페이지 하단에 '내 찜 목록 보러가기' 전용 버튼 노출
- **권한별 렌더링 분기 고도화**: 관리자(`ROLE_ADMIN`) 전용 대시보드 버튼과 일반 유저 찜 목록 버튼을 명확히 분리하여 레이아웃 최적화

#### 2026-05-29
- **사용자 권한별 기능 접근성 강화**: 일반 유저 전용 '내 찜 목록 보러가기' 버튼을 로그아웃 버튼 바로 위에 단독 배치하여 유저 동선 최적화
- **버튼 디자인 및 상호작용 고도화**: 특수 기능 버튼(관리자/찜 목록)에 플레이스테이션 브랜드 컬러를 적용하고, 전역 CSS 충돌을 방지하기 위해 인라인 스타일 기반의 동적 호버(Hover, `onMouseEnter`/`onMouseLeave`) 이벤트 구현
